# ITAI.EDU — Professional Certificate in Data Analytics

A professional certificate landing site for the ITAI Data Analytics program, featuring a multi-page architecture with glassmorphism design.

## How to Run Locally

Open `index.html` in any modern web browser. No build tools or server required.

## Project Structure

```
/
├── index.html          # Home page — hero, trust bar, program overview, why data analytics
├── curriculum.html     # Curriculum page — tools, modules, learning path timeline
├── outcomes.html       # Outcomes page — learning outcomes, career paths, testimonials
├── faq.html            # FAQ page — frequently asked questions with accordion
├── enroll.html         # Enrollment page — pricing CTA and money-back guarantee
├── css/
│   ├── styles.css      # Global styles — base, layout, typography, animations
│   └── components.css  # Component styles — glass cards, badges, ribbons, buttons
├── js/
│   ├── main.js         # Core JS — scroll animations, salary bars, copyright year
│   ├── navigation.js   # Navigation JS — mobile menu, active link highlighting
│   └── faq.js          # FAQ JS — accordion expand/collapse logic
└── assets/
    └── images/         # Placeholder for future images and icons
```

## Technologies

- **HTML5** — Semantic markup with ARIA accessibility attributes
- **Tailwind CSS** (via CDN) — Utility-first CSS framework
- **Font Awesome** (v6.4.0, via CDN) — Icon library
- **Google Fonts** — Plus Jakarta Sans typeface
- **Vanilla JavaScript** — No frameworks or dependencies
